# Baseline methodology and interpretation

These results were generated by `src/run_baselines.py` for Bekzat Gulzhigit uulu's baseline and Linear Regression contribution. They provide a benchmark for the group's remaining models.

## Data and preprocessing

All 35,040 rows were retained. There are no missing values or exact duplicate rows in the included source file. The target has eight distinct values, from 0.00 to 0.07 in steps of 0.01; 20,990 observations have a recorded zero. A training-quartile IQR rule flags 437 high target values across the full dataset. They are saved in `flagged_target_rows_retained.csv` and retained, since the flag does not demonstrate a measurement error.

The CSV puts each date's midnight row after its 23:45 row. Dates are parsed literally with `%d/%m/%Y %H:%M`, then sorted chronologically. No inferred next-day shift is applied. The saved membership file fixes the exact observations used by this analysis.

## Models and validation

- Training-mean reference: a constant prediction equal to the training target mean.
- Proportional baseline: ordinary least squares on `Usage_kWh` with no intercept.
- Usage-only Linear Regression: ordinary least squares on `Usage_kWh` with an intercept.
- Expanded Linear Regression: ordinary least squares with an intercept, six standardized numerical inputs, and two one-hot-encoded categorical inputs. The encoder drops the first category and ignores unknown categories. Preprocessing is fitted only on the relevant training partition.

Expanded inputs are `Usage_kWh`, `Lagging_Current_Reactive.Power_kVarh`, `Leading_Current_Reactive_Power_kVarh`, `Lagging_Current_Power_Factor`, `Leading_Current_Power_Factor`, `NSM`, `Day_of_week`, and `Load_Type`. They become 14 transformed inputs. `WeekStatus` is omitted as redundant with day of week. Dates and source row IDs are not model features.

`TimeSeriesSplit(n_splits=3, gap=0)` provides three expanding validation folds entirely inside the first 70%. Each validation fold has 6,132 observations. No hyperparameters were tuned. All final models were fitted on the first 70% and evaluated on the unchanged last 30%.

The training-calibrated formulas are:

```text
Proportional prediction = 0.000454332565 × Usage_kWh
Usage-only prediction = 0.000475729240 × Usage_kWh − 0.001495915173
```

The proportional coefficient is learned from this dataset's training portion. It is not an independently sourced electricity-grid emission factor.

## Interpretation

The usage-only linear model has the lowest test MAE and RMSE among these models; the comparison table is in the root README and exact values are in `metrics.csv`. Average validation RMSE is 0.001973 for usage-only Linear Regression and 0.002065 for expanded Linear Regression. The results support retaining a simple benchmark; they do not establish the outcome of the planned tree-model comparison. No significance test was performed.

`expanded_coefficients.csv` records the fitted coefficients after preprocessing. These are neither causal effects nor a complete feature-importance analysis. The daily plot averages observations only for visualization; all reported errors use individual observations.

## Limitations

The target is coarse and strongly predictable from electricity usage. This is consistent with a rounded or derived target, but the analysis does not prove how the emissions column was produced. Recorded zero values are not automatically missing data or proof of physically zero emissions.

Raw linear predictions are not clipped or rounded. Usage-only Linear Regression produces 2,291 negative test predictions, with a minimum around -0.001496. Expanded Linear Regression produces 3,052, with a minimum around -0.004324. Any nonnegative alternative should be evaluated using training-period validation before changing the agreed method.

The target column name and UCI's unit description conflict. MAE and RMSE are reported in native target units, without conversion to kilograms or tonnes.

These models estimate a recorded target using measurements from the same interval; they do not forecast future emissions before electricity usage is known. One facility, one year, potentially correlated neighboring observations, and a September–December test period limit generalization. High R² is not percentage accuracy or proof of performance at other facilities.
